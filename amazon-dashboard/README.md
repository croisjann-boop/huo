# 亚马逊销售经营看板

基于你提供的单文件 `index.html` 整理而成的可运行代码项目。保留深蓝侧栏、橙色重点色及原型的 7 个页面，并将数据、指标计算、页面渲染、交互和样式拆开，方便继续开发。

技术：原生 HTML / CSS / JavaScript，源码使用 ES Modules；构建时生成内含全部样式和脚本的独立 HTML。**没有第三方依赖，无需 npm install**。

## 快速启动

直接使用：解压后双击根目录的 **index.html**。不需要安装 Node.js 或启动服务，7 个页面和全部前端交互均包含在文件中。

开发或通过本地 HTTP 使用：需要 Node.js 20 或更新版本。Windows 可以双击 `启动看板.cmd`；也可以在项目目录打开终端，执行：

```powershell
node scripts/server.mjs
```

随后在浏览器打开 **http://127.0.0.1:5173**。停止服务：在启动它的终端按 `Ctrl+C`。

如果端口被占用：

```powershell
node scripts/server.mjs --port=5174
```

若已安装 npm，也可用 `npm run dev`、`npm run build`、`npm test`。

修改 `src/` 源码后执行 `node scripts/build.mjs`，再刷新浏览器；启动本地服务器时也会自动构建。根目录 `index.html` 是生成文件，应通过修改 `src/template.html`、JS 和 CSS 来维护。

## 数据口径

- 所有数据均为虚构。固定截止日为 **2026-11-10**，共 30 天 × 18 个 SKU = 540 条日记录，覆盖 3 个国家 / 店铺、2 个一级品类。原型生成公式已保留。
- “本月累计”按演示截止日计算，为 11 月 1–10 日；最近 30 天为 10 月 12 日至 11 月 10 日。不会随电脑日期变化。
- 推广占比 = 广告花费 / 净销售额；退款率 = 退款件数 / 销量；CTR = 点击 / 展现；CVR = 广告订单 / 点击；CPC = 花费 / 点击；ACOS = 花费 / 广告归因销售额；达成率 = 净销售额 / 目标。
- 百分比均在计算比值后乘以 100。先累加分子、分母，再计算汇总比率，避免直接平均百分比。分母为 0 时显示 `—`，跳过该比率的异常判断。
- 访客是电脑端、手机端设备访次之和，不是跨设备去重人数。广告归因窗口模拟为 7 天。
- 广告类型固定拆分为 58% / 18% / 14% / 10%，不是独立采集的真实渠道报表。页面金额按美元四舍五入展示，因此展示值相加可能存在尾差；底层合计一致。
- 阈值规则：ACOS、退款率、CPC、推广占比、花费为最高值；其他项为最低值。等于阈值时视为达标。阈值针对所选期间的 SKU 累计值，不自动折算到每天。

## 接入真实数据时改哪里

`src/main.js` 中目前通过 `createMockRows()` 载入数据。接入后端时，将其替换为经过验证的 API 返回记录，并让截止日、店铺列表来自同一数据源；同步修改 `mock-data.js` 的固定日期、页面侧栏和 README。

每条记录代表“日期 × 店铺 × SKU”，需要以下字段：

| 字段 | 含义 / 类型 |
| --- | --- |
| date | `YYYY-MM-DD`，统一业务时区后的日期字符串 |
| country, shop | 国家、店铺名称，字符串 |
| category1, category2, category3 | 三级品类名称，字符串 |
| sku, asin | 产品标识，字符串 |
| revenue, units | 净销售额（USD）、销量 |
| adSpend, clicks, impressions | 广告花费（USD）、点击、展现 |
| adRevenue, adOrders | 广告归因销售额（USD）、广告订单 |
| desktopVisits, mobileVisits | 电脑端、手机端访次 |
| refunds, target | 退款件数、期间日分解目标（USD） |

数值字段需要为有效数值，并在接入层完成币种转换、去重、归因和退款口径对齐。若真实数据允许负销售额或目标缺失，应补充对应指标规则。

当前交付是**可继续开发的前端演示项目**：没有真实亚马逊 API、账号登录、数据库、服务端权限、后台定时同步或大模型调用。“AI基础分析”实际为本地规则判断；展示频率和周报时间为演示设置。生产接入需要另行实现这些后端能力，密钥应保存在后端。

诊断标准存储键为 `amz-threshold`，频率为 `amz-frequency`，兼容读取原文件的 `demo-frequency`。设置只对当前浏览器的同一来源有效；直接打开本地文件时，存储行为取决于浏览器，无法保存时会提示。角色范围仅供前端演示；真实数据必须由服务端按登录用户做授权校验。
