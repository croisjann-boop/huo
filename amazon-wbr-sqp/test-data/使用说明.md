# Amazon WBR & SQP 演示测试数据

全部数据均为人工虚构，不含真实店铺、客户或交易信息。币种统一为 USD。

## 一步导入

在该项目网页顶部点击 Import Backup，选择 `DEMO-workspace.json`。这个文件会替换该页面本地工作区的配置和数据；如已有自己的数据，先用 Export Backup 导出保存。

导入后当前周期为 2026-W45（11月2日—11月8日），对比周期为 2026-W44（10月26日—11月1日）。

## 预期结果

| 指标 | W44 上周 | W45 本周 | 变化 |
|---|---:|---:|---:|
| 销售额 | $20,000 | $20,000 | 0% |
| 净利润 | $4,000 | $3,400 | -15% |
| 广告花费 | $3,000 | $3,600 | +20% |
| 广告花费 / 总销售额 | 15% | 18% | +3 个百分点 |

原项目将「广告花费 / 总销售额」标为 Overall ACoS，按通常使用口径应称 TACOS；本数据没有广告归因销售额，不能算真正 ACOS。演示保留原项目代码，不把其标签视为正确口径。

- DEMO-CUP：利润从 $1,200 增至 $2,250，增长贡献 $1,050。
- DEMO-CHAIR：利润从 $2,000 降至 $1,000，下降 $1,000。
- DEMO-LAMP：利润从 $800 降至 $150，下降 $650。
- 三个搜索词合计搜索量从 240,000 降至 216,000（-10%）。
- 折叠椅关键词购买份额 20%→12%，露营灯关键词 10%→6%，用于展示份额流失提示。

## 页面菜单

- Dash_Executive：经营总览及规则提示。
- Config_Param：周期设置、SKU 与父 ASIN 映射。
- Raw_Sellerboard / Raw_Seller_Central / Raw_SQP：原始表和 CSV 导入。
- Fact_Sales / Fact_SQP：汇总匹配后的数据。
- Anly_SKU_Performance / Anly_Keyword_Performance：商品、关键词的周期对比。

CSV 是独立分表导入用；SQP 的比例采用 0—1 小数。JSON 一次性包含配置与全部分表，演示时最方便。
