# 亚马逊 WBR / SQP 测试演示

本目录保存 Theseus Workshop / HyVoid 的开源项目及本次演示使用的虚构数据，与仓库根目录的 Seller Insight 看板相互独立。

## 本机启动

安装 Node.js 后，在本目录执行：

```sh
npm ci --ignore-scripts
npm run build
npm run preview -- --host 127.0.0.1
```

打开终端显示的地址。在顶部点击 **导入备份**，选择 `test-data/DEMO-workspace.json`，确认导入后即可查看演示。导入将替换该网页的本地配置和分表，已有数据请先 导出备份。

源码不能直接双击 index.html 运行，需要上述安装和构建过程。

## 测试数据

均为人工虚构；3 个 SKU，14 天，3 个搜索词；币种 USD。本周 2026-W45 对比上周 2026-W44：

| 指标 | 上周 | 本周 |
|---|---:|---:|
| 销售额 | 20,000 | 20,000 |
| 净利润 | 4,000 | 3,400 |
| 广告花费 | 3,000 | 3,600 |

保温杯利润增长 1,050；露营椅和露营灯利润分别下降 1,000、650。分表和完整说明见 `test-data/使用说明.md`。

## 显示与原项目边界

- 本版已将原项目的 Overall ACoS 标签更正为「广告总费比（TACOS）」；计算仍为广告花费÷总销售额。没有广告归因销售额，不能据此计算真正 ACOS。
- 仪表板直接切换周期可能没有同步更新正确的对比周期。推荐在「参数设置」中明确指定两期；数据包已设置好。
- 诊断是规则提示，不代表真实因果已确认。
- 存储源码不等于部署网页；原项目在线演示曾引用未编译源码而显示空白。
